The TypeError: fetch failed is just a warning — it means Expo CLI tried to check package versions online but your company network blocked it. The Metro Bundler is still running despite this error.
​

What You Need To Do Now
Step 1 — Start with offline flag:

text
set EXPO_OFFLINE=1
npx expo start --lan -c
Step 2 — Check what IP Metro is running on. After starting, you'll see something like:

text
Metro waiting on exp://172.30.100.108:8081
Step 3 — Open Expo Go on your phone, tap "Enter URL manually" and type:

text
exp://172.30.100.108:8081
(Use whatever IP shows in your terminal, not necessarily this one)
