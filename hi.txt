Problem Statement — URTI Leave Management Automation
Project Name: Agentic URTI Leave Processing System
Department: Crew Operations, IndiGo (InterGlobe Aviation Ltd.)
Prepared By: Crew Tech Team
Date: March 2026
Version: 1.0

1. Background
IndiGo crew members are entitled to URTI (Upper Respiratory Tract Infection) leave as a separate, protected leave category distinct from standard Sick Leave (SL). When a crew member is diagnosed with URTI by an ENT specialist, their previously marked Sick Leave must be reclassified as URTI leave in the Crew Leave Management System (CLMS). This reclassification directly impacts payroll, leave balances, and in some cases, eligibility for efficiency bonuses and arrears.

2. Current Process
The existing workflow is entirely manual and email-driven:

Base team confirms URTI diagnosis and sends an email to the Crew Tracking team

Crew Tracking team manually logs into CLMS and verifies leave balances

Team manually checks the crew's calendar bucket and roster markings

SL is manually reversed and URTI code is applied date by date

If LWP was marked, payroll team is notified separately via email

A 7-day follow-up is done manually to confirm CLMS was updated correctly

3. Problem Statement
The current URTI leave update process is entirely manual, email-dependent, and lacks standardisation — leading to delays, errors, payroll discrepancies, and compliance risks for IndiGo's crew operations.

4. Key Pain Points
#	Pain Point	Business Impact
1	Requests sent via unstructured emails	Missing fields, inconsistent format, rework
2	No automated duplicate request detection	Same leave processed twice → payroll error
3	Manual CLMS login for every request	30–45 min per case, scales poorly
4	Calendar bucket logic done manually	Wrong bucket deductions, balance errors
5	LWP reversal not always flagged to payroll	Crew misses arrears and efficiency bonus
6	No audit trail of changes made	Compliance and accountability risk
7	7-day follow-up depends on individual memory	Frequently missed, unverified updates
8	Process halts if key person is unavailable	Single point of failure, operational risk
9	No real-time status visibility	Base team unaware of request progress
10	Document verification done manually	Invalid or missing certificates not caught early
5. Scope
In Scope:

Automated email parsing and data extraction

Document verification (Medical Certificate, Fitness Certificate, URTI Format)

Duplicate request detection

CLMS leave balance verification

Calendar bucket detection and adjustment

SL reversal and URTI code application

LWP reversal and payroll team notification

Automated 7-day follow-up verification

Out of Scope:

Other leave types (PL, EL, etc.)

Roster scheduling or duty assignment

Payroll calculation or disbursement

Crew medical records management

6. Objective
To design and implement an agentic AI workflow using Microsoft Copilot Studio and Power Automate that:

Automatically triggers on incoming URTI request emails

Validates all required documents and crew data without human intervention

Applies leave updates in CLMS safely using atomic transactions

Handles special cases (bucket reversal, LWP) with human-in-the-loop controls

Notifies all relevant stakeholders automatically

Maintains a complete audit trail of every action taken
