## The Core Problem with Power BI + Agents

Power BI is fundamentally a **read-only visualization layer** — it doesn't natively support stateful agents. But here's what can get you close to your goal:

---

## Option 1: DAX Dynamic Text Measures *(Best no-deploy option)*

This is underrated and genuinely powerful. You write measures that generate full narrative text, and they **auto-respond to every filter/slicer change**.

```dax
Dynamic Summary = 
VAR _rev = [Total Revenue]
VAR _revLY = [Revenue LY]
VAR _growth = DIVIDE(_rev - _revLY, _revLY)
VAR _topProduct = CALCULATE(TOPN(1, VALUES(Products[Name]), [Revenue]))
VAR _trend = IF(_growth > 0, "▲ up", "▼ down")

RETURN
"Revenue is " & FORMAT(_rev, "#,##0") & 
" — " & _trend & " " & FORMAT(ABS(_growth), "0.0%") & 
" vs last year. Top performer: " & _topProduct & "."
```

Put this in a **Card visual** or **Smart Narrative** — it becomes a living summary that reacts to any filter. You can make it as rich as you want.

---

## Option 2: Power BI Copilot *(If your org has it)*

This is the closest to a true agent **without any deployment**:

- Generates AI summaries that adapt to report context
- Answers natural language questions about your data
- Creates visuals from prompts
- **Requirement**: Fabric F64 capacity or Power BI Premium P1/P2

> Check with your admin — many companies already have this and don't use it.

---

## Option 3: Power Automate + OpenAI Connector *(Low-code agent)*

This is available **inside Power BI Desktop** via the Power Automate visual:

```
Trigger: Button click in Power BI visual
→ Power Automate Flow
→ Passes current filter context as parameters
→ Calls OpenAI / Azure OpenAI HTTP connector
→ Returns dynamic GPT-generated summary back to report
```

No VS Code, no GitHub — just Power Automate flows which you likely already have access to. The key trick is **passing slicer values as dynamic parameters** into the flow.

---

## Option 4: Custom Connector via Power Query *(HTTP to any LLM)*

If your company allows external HTTP calls in Power Query, you can hit an LLM API directly:

```powerquery
let
    body = Json.FromValue([prompt = "Summarize: Revenue=" & Text.From(revenue)]),
    response = Web.Contents("https://api.openai.com/v1/chat/completions", 
        [Headers=[Authorization="Bearer YOUR_KEY"], Content=body])
in
    Json.Document(response)
```

Limitation: this refreshes on schedule, not on filter change.
