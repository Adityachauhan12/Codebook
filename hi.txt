📋 Your Use Case Summary
Your agent:
 
Triggers on incoming emails about URTI leave updates for crew
Extracts IGA number, Crew name, From Date, To Date for URTI leave
Needs to verify URTI leave eligibility, pending leaves, and existing SL/PL conflicts
Updates the database accordingly
 
-------------------------------------------------
🔍 RELEVANT TABLES FOR READING (Fetch APIs)
1. Core Crew & Identification Tables
Table Name	Purpose for Your Use Case	Key Columns
M_CLMS_Crew	Master crew table -> Validate IGA number (CrewID), get crew details, check eligibility status, base assignment	CrewID, CrewName, Email, Designation, Base, DOJ, Active, Status, LeaveTypeId
M_LeaveYear ->	Determine current leave year for balance calculations	LeaveYearId, LeaveYearStartDate, LeaveYearEndDate, IsActive
M_LMS_LeaveType->	Get LeaveTypeID for URTI, SL, PL	LeaveTypeID, LeaveType, Description
M_LMS_StatusType->	Status codes for leave requests (Pending, Approved, etc.)	StatusTypeID, StatusType
 
2. Leave Balance & Eligibility Tables
Table Name	Purpose for Your Use Case	Key Columns
M_CLMS_LeaveBalance	Critical - Check current URTI/SL/PL balance for the crew member	CrewID, LeaveTypeID, Balance, LeaveYearId
T_Crew_Leaves_Allocation	Annual leave allocations - verify total entitled leaves	Crewid, LeaveTypeId, LeavesAllotted, LeaveYearId, IsActive
CrewBalanceUpdateByScheduler	Track SL and URTI balance changes, eligibility context	crewID, OldURTIBalance, updatedURTIBalance, OldSLBalance, updatedSLBalance, EligibleMonths, LeaveYearID
 
3. Existing Leave Request Tables (Check Conflicts)
Table Name	Purpose for Your Use Case	Key Columns
T_CLMS_LeaveReqMaster	Check if SL/PL already exists for the requested dates	CrewID, LeaveTypeid, StatusTypeID, FromDT, ToDt, LeaveDetailID
T_CLMS_LeaveReqDetail	Detailed breakdown of existing leave requests	LeaveDetailID, LeaveTypeID, NoOfLeaves, Balance, FromDt, ToDt
T_Crew_LeaveYear	Map crew to leave year, track base changes	Crewid, LeaveYearId, Curr_Base, Suggested_SL, IsActive
 
4. Supporting/Reference Tables
Table Name	Purpose for Your Use Case	Key Columns
M_CLMS_GNDCODE	Ground codes for leave/duty activities	ID, Code
SickLeave_Email	Base-wise email IDs for sick leave notifications	Base, EmailID
M_CLMS_BaseEmail	Email distribution for notifications	Base, Email, CCEmail
 
✏️ RELEVANT TABLES FOR UPDATING (Update APIs)
Table Name	Update Purpose	Key Columns to Update
T_CLMS_LeaveReqMaster	INSERT new URTI leave request OR UPDATE existing conflicting SL/PL	CrewID, LeaveTypeid, StatusTypeID, FromDT, ToDt, RequestedDate, CrewComment, ActionDate
T_CLMS_LeaveReqDetail	INSERT leave breakup details OR UPDATE if modifying existing	LeaveDetailID, LeaveTypeID, NoOfLeaves, Balance, CurrentLeave, FromDt, ToDt
M_CLMS_LeaveBalance	UPDATE leave balance after approval/change	CrewID, LeaveTypeID, Balance, LeaveYearId
CrewBalanceUpdateByScheduler	INSERT record to track URTI/SL balance updates	crewID, OldURTIBalance, updatedURTIBalance, UpdatedTime, LeaveYearID
T_CLMS_GNDCodes	INSERT/UPDATE ground code transactions if needed	EMPNO, GNDACTCODE, STARTTIME, ENDTIME, ApprovedStatus
