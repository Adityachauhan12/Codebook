📖 Tables for READ APIs
 
1. Core Crew Identification & Validation

Table Name	Purpose	Key Columns to Fetch

M_CLMS_Crew	Validate IGA number, get crew details, check active status, base assignment	CrewID, CrewName, Email, Designation, Base, DOJ, Active, Status, LeaveTypeId
 
2. Leave Configuration & Reference Tables

Table Name	    Purpose	    Key Columns to Fetch

M_LeaveYear->	Get current active leave year for balance calculations	LeaveYearId, LeaveYearStartDate, LeaveYearEndDate, IsActive

M_LMS_LeaveType->	Get LeaveTypeID for URTI, SL (Sick Leave), PL (Privileged Leave)	LeaveTypeID, LeaveType, Description

M_LMS_StatusType	Get status codes (Pending, Approved, Rejected, etc.)	StatusTypeID, StatusType
 
3. Leave Balance & Eligibility Tables

Table Name	 Purpose	Key Columns to Fetch

M_CLMS_LeaveBalance	 Critical - Check current URTI/SL/PL balance for the crew	BalanceID, CrewID, LeaveTypeID, Balance, LeaveYearId

T_Crew_Leaves_Allocation	Get total annual leave entitlement/allocation	Crewid, LeaveTypeId, LeavesAllotted, LeaveYearId, IsActive

CrewBalanceUpdateByScheduler	Track historical SL/URTI balance changes, eligibility months	crewID, OldURTIBalance, updatedURTIBalance, OldSLBalance, updatedSLBalance, EligibleMonths, LeaveYearID
 
4. Existing Leave Requests (Check Conflicts with SL/PL)

Table Name	Purpose	Key Columns to Fetch

T_CLMS_LeaveReqMaster	Check if SL/PL already marked for requested date range	LeaveDetailID, CrewID, LeaveTypeid, StatusTypeID, FromDT, ToDt, RequestedDate

T_CLMS_LeaveReqDetail	Get detailed breakdown of existing leave requests	LeaveReqSubId, LeaveDetailID, LeaveTypeID, NoOfLeaves, Balance, FromDt, ToDt
 
5. Crew-Leave Year Mapping

Table Name	   Purpose	Key Columns to Fetch

T_Crew_LeaveYear	Map crew to leave year, track base changes/transitions	Crewid, LeaveYearId, Curr_Base, Pre_Base, Suggested_SL, IsActive
 
6. Supporting/Reference Tables

Table Name	Purpose	Key Columns to Fetch

M_CLMS_GNDCODE	Ground codes for leave activities (if needed for validation)	ID, Code

SickLeave_Email	Base-wise email IDs for notifications	Base, EmailID
